## In-file TOCs

I'm sure I can't be the only person doing this but I haven't seen it anywhere else so I thought it's worth talking about: you can use custom fold markers as an ad-hoc <abbr title="Table Of Contents">TOC</abbr>.

It is fairly simple: just place `{{{1` in a comemnt wherever you want to fold
- `{{{` is the default fold marker
- `1` puts it at "fold level 1" i.e. put all of them at the same level despite the missing the closing `}}}` markers. Otherwise each marker would nest the fold one level deeper.

To make sure that the correct vim fold settings are there, I usually just add this [modeline](https://neovim.io/doc/user/usr_21.html#_modelines)[^security] at the end of the file:

<CollapsedContent summary="vim: fdm=marker:fen:fdl=0:">
- `fdm=marker`: (`foldmethod=marker`) Sets the method for folding code. marker looks for specific markers (default is `{{{` and `}}}`) to define the boundaries of a fold.
- `fen`: (`foldenable`) Enables code folding for this file. If this were nofen, folding would be disabled.
- `fdl=0`:(`foldlevel=0`) Sets the starting fold level. A level of 0 means that all folds are closed by default when you open the file

</CollapsedContent>

## Here's a small example

### Before folding

```lua title="autocmds.lua BEFORE folding"
-- {{{1 Disable autoformat for some filetypes
vim.api.nvim_create_autocmd({ "FileType" }, {
  pattern = { "python", "toml" },
  callback = function()
    vim.b.autoformat = false
  end,
})

-- {{{1 Add new filetype patterns

-- |  {{{1 nix
vim.filetype.add({
  filename = { ["flake.lock"] = "json" },
})

-- |  {{{1 poetry
vim.filetype.add({
  filename = { ["poetry.lock"] = "toml" },
})

-- |  {{{1 docker
vim.filetype.add({
  pattern = { ["[Dd]ockerfile.*"] = "dockerfile" },
})

-- vim: fdm=marker:fen:fdl=0:
```

### After folding

```lua title="autocmds.lua AFTER folding"
-- {{{1 Disable autoformat for some filetypes
-- {{{1 Add new filetype patterns
-- |  {{{1 nix
-- |  {{{1 poetry
-- |  {{{1 docker
```
