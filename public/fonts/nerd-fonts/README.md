# Hosted Nerd Fonts

These webfonts come from the official [Nerd Fonts 3.5.1 release](https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.5.1):

- `FiraCode.zip` (`239395baf60c89b2eaf4862b6b09db0ef95605cd3e8eef51c00345822a81a665`)
- `JetBrainsMono.zip` (`fab782a66f7d3019da64f6572db9fc5d3a4bcb19f9fa13e2d8a62e3693d6396e`)

Only the regular and bold `NerdFont` variants are hosted. They were converted
from TTF to WOFF2 with FontTools. The Font Logos range (`U+F300–F385`) was
removed because the Nerd Fonts 3.5.1
[license audit](https://github.com/ryanoasis/nerd-fonts/blob/v3.5.1/license-audit.md)
lists that glyph source as unlicensed.
